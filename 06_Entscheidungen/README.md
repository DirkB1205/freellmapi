# Entscheidungs-Log

## Zweck

Dokumentation von Architektur-Entscheidungen (ADRs), die über den Projektrahmen hinaus Bestand haben. Jede Entscheidung hat Kontext, Alternativen und Konsequenzen.

## Format

```markdown
---
tags: [ADR, <Bereich>]
created: <Datum>
status: [accepted | deprecated | superseded]
---

# <Entscheidungs-ID> — <Titel>

## Kontext
Warum wurde diese Entscheidung nötig?

## Alternativen
Welche Alternativen wurden erwogen?

## Entscheidung
Was wurde gewählt und warum?

## Konsequenzen
Was sind die Folgen (positiv, negativ)?

## Gegenmaßnahmen
Gibt es something, das später revidiert werden sollte?
```
