# Telegram-Medien

Alle Bilder und Videos, die du per Telegram an @dirkb_bot sendest, werden hier abgelegt (automatischer Download).

Falls du Dateien manuell bereitstellen willst, lege sie einfach in dieses Verzeichnis. Das Analyse‑Pipeline‑Script wird beim nächsten Lauf alle `*.jpg`, `*.png`, `*.mp4` usw. verarbeiten.
