# AI-Content-Studio (100% Lokal & Kostenlos)

Ein vollständig lokales, produktionsreifes KI-Content-Studio für Windows 11 zur automatisierten Trendanalyse, Viralitätsbewertung, Skripterstellung, Sprachsynthese, Avatar-Videogenerierung und Untertitelung.

## Features
- **0 € laufende Kosten**: Läuft komplett lokal auf Ollama, FFmpeg, Whisper, XTTS-v2 / Kokoro.
- **Trendanalyse**: Automatisierte Suche auf Reddit, Hacker News, GitHub Trending, RSS.
- **Viralitäts-Score**: Gewichtete Bewertung (40% Engagement, 25% Shares, 20% Kommentare, 10% Likes, 5% Aktualität).
- **Avatar Management**: Bildanalyse, Qualitätsprüfung und Mehrfach-Varianten (Business, IT Consultant, AI Expert, etc.).
- **Sprachausgabe (TTS)**: XTTS-v2, Kokoro, Piper für natürliche deutsche Sprachausgabe mit Umlaute-Unterstützung.
- **Video Pipeline**: LivePortrait / MuseTalk Avatar-Animation + Whisper Untertitel + FFmpeg Rendering (1080x1920, 30 FPS).
